1. What is an LLM?

A Large Language Model (LLM) is a neural network trained on a very large collection of text to model the statistical structure of language.

At its core, a language model estimates:

P(next token∣previous tokens)

In simpler terms:

Given everything I've seen so far, what token is most likely to come next?

For example:

The capital of France is

The model might assign probabilities approximately like:

Paris      0.95
London     0.01
Berlin     0.005
...

The model then generates a token and repeats the process.

Therefore, a fundamental way to think about an LLM is:

Context
   ↓
Predict next token
   ↓
Add token to context
   ↓
Predict next token
   ↓
Repeat

This deceptively simple operation becomes extremely powerful when the model has:

billions of parameters
enormous training datasets
large compute budgets
sophisticated neural-network architectures
extensive post-training

3. Pretraining Data

Large language models require enormous datasets.

A significant source of this data is the public internet.

One example discussed by Karpathy is FineWeb, a large-scale dataset derived from web data.

The internet itself is not directly fed into the neural network.

5. Tokenization

Neural networks operate on numbers.

They don't directly consume English words, paragraphs, or sentences.

Therefore, text needs to be converted into tokens.

Example:

"Machine learning is powerful"

might become something conceptually like:

["Machine", " learning", " is", " powerful"]

However, tokens are not necessarily complete words.

A tokenizer can split text into:

words
subwords
characters
bytes

depending on the tokenizer.

For example:

unbelievable

could conceptually become:

un
believ
able

The exact representation depends on the tokenizer.

6. Why Tokenization Matters

Tokenization creates a bridge:

Human language
      ↓
Tokenizer
      ↓
Token IDs
      ↓
Neural network

Each token is mapped to an integer.

For example:

"Hello world"

could become:

[15496, 995]

The exact numbers are determined by the tokenizer's vocabulary.

Therefore, the model isn't literally seeing:

Hello world

It sees something closer to:

[15496, 995]

These IDs are then converted into continuous numerical vectors called embeddings.

8. The Transformer

The architecture behind modern LLMs is primarily the Transformer.

The Transformer was introduced in the 2017 paper:

Attention Is All You Need

The architecture allows neural networks to process sequences while modeling relationships between tokens.

A simplified Transformer looks like:

Token IDs
    ↓
Token Embeddings
    ↓
Transformer Block
    ↓
Transformer Block
    ↓
Transformer Block
    ↓
...
    ↓
Final Representation
    ↓
Language Modeling Head
    ↓
Logits

Modern LLMs may contain many Transformer blocks.

Each block performs transformations that allow the model to build increasingly sophisticated representations of the input.

9. Embeddings

Token IDs themselves don't contain meaningful mathematical relationships.

For example:

"cat" → 5321
"dog" → 9274

The numbers 5321 and 9274 don't inherently tell the neural network that cats and dogs are related.

Instead, tokens are mapped into vectors.

For example:

cat → [0.21, -0.43, 0.72, ...]
dog → [0.18, -0.39, 0.68, ...]
car → [-0.72, 0.91, -0.14, ...]

These vectors are learned during training.

The model therefore develops a geometric representation of linguistic information.

10. Attention

One of the most important components of the Transformer is self-attention.

Attention allows tokens to interact with other tokens in the sequence.

Consider:

The animal didn't cross the road because it was tired.

The model needs to determine what "it" refers to.

Attention allows information from different positions in the sequence to interact.

Conceptually:

The ──────────────┐
animal ───────────┤
didn't ───────────┤
cross ────────────┤
the ──────────────┤
road ─────────────┤
because ──────────┤
it ───────────────┤
was ──────────────┤
tired ────────────┘
        ↓
    Attention

The model learns which tokens should influence each other.

11. The Residual Stream

Transformer architectures repeatedly transform representations.

A useful mental model is to imagine a shared information highway:

Input representation
        │
        ▼
   Residual Stream
        │
   ┌────┴────┐
   │         │
Attention   MLP
   │         │
   └────┬────┘
        │
        ▼
Updated representation

Each Transformer block modifies the representation.

As the representation passes through more layers, the model can construct increasingly sophisticated information.

Early layers may capture relatively simple patterns.

Later layers can represent more complex relationships and abstractions.

12. Training the Language Model

The fundamental training objective is surprisingly simple:

Predict the next token.

Suppose the training sequence is:

The cat sat on the mat

The model can create multiple training examples:

Target: cat


Input: The cat
Target: sat


Input: The cat sat
Target: on


Input: The cat sat on
Target: the


Input: The cat sat on the
Target: mat

So one sequence provides many prediction problems.

14. Loss and Optimization

The model initially performs poorly.

Its predictions might be nearly random.

Training improves the model by minimizing a loss function, typically cross-entropy loss for next-token prediction.

Conceptually:

Training data
     ↓
Model prediction
     ↓
Compare with correct token
     ↓
Calculate loss
     ↓
Backpropagation
     ↓
Gradient
     ↓
Update parameters
     ↓
Repeat

This happens an enormous number of times.

The parameters of the neural network are gradually adjusted so that the model becomes better at predicting tokens.

15. What Does the Model Actually Learn?

This is one of the most interesting ideas.

The model isn't explicitly programmed with rules such as:

IF subject = "France"
THEN answer = "Paris"

Instead, patterns are learned through optimization.

The parameters encode statistical structures learned from the training data.

The model can therefore learn relationships involving:

grammar
syntax
facts
programming patterns
writing styles
semantic relationships
mathematical patterns
reasoning patterns
associations between concepts

However, these aren't stored like entries in a traditional database.

A useful mental model is:

The parameters contain a distributed, imperfect representation of patterns learned from training.

17. Autoregressive Generation

Suppose the prompt is:

The weather today is

The model predicts:

beautiful

Now the context becomes:

The weather today is beautiful

The model predicts the next token.

Maybe:

and

Now:

The weather today is beautiful and

Then:

warm

And so on.

Therefore:

Prompt
 ↓
Token 1
 ↓
Token 2
 ↓
Token 3
 ↓
Token 4
 ↓
...

This process is called autoregressive generation.

18. Sampling

The model doesn't always have to select the highest-probability token.

It can sample from the probability distribution.

For example:

Paris      0.70
London     0.15
Berlin     0.10
Madrid     0.05

Different sampling strategies can produce different outputs.

This is part of why the same prompt can sometimes generate different responses.

Important inference concepts include:

temperature
top-k sampling
top-p / nucleus sampling
greedy decoding

These control how deterministic or diverse generation is.

19. GPT-2 as a Concrete Example

Karpathy uses GPT-2 as a concrete example because it makes the entire LLM pipeline easier to understand.

GPT-2 is useful pedagogically because it is:

publicly documented
relatively small compared with modern frontier models
reproducible

Karpathy also discusses reproducing GPT-2 training through his llm.c work.

This is an important lesson for someone learning LLM engineering:

Don't only study modern billion-parameter models as black boxes. Build or reproduce a smaller model so you understand what is happening underneath.

20. Base Models

Pretraining produces a base model.

The base model's fundamental behavior is:

Given previous tokens,
predict what token comes next.

This doesn't necessarily mean that it behaves like ChatGPT.

For example, if you prompt a base model with:

User: What is the capital of France?
Assistant:

it may not necessarily respond like a polished assistant.

It might continue the text in whatever way is statistically likely based on its training distribution.

This distinction is extremely important.

21. Llama 3.1

Karpathy demonstrates inference using a Llama 3.1 base model.

This illustrates the difference between interacting with a raw pretrained model and interacting with an instruction-tuned assistant.

A base model can be extremely capable while still not behaving like a conversational assistant.

That capability comes from the pretrained representation.

The assistant-like behavior is added later.

27. Questions I Should Be Able to Answer After This Section

You should be able to explain these without looking at the notes:

What is an LLM?

A neural network trained to model the probability distribution of token sequences, commonly by predicting the next token given previous tokens.

What is tokenization?

The process of converting raw text into discrete tokens that can be represented numerically and processed by a neural network.

Why can't we feed raw text directly into a neural network?

Neural networks operate on numerical representations, so text must first be converted into token IDs and then embeddings.

What does a Transformer do?

It processes token representations using mechanisms such as self-attention and feed-forward networks to build contextual representations.

What is the fundamental training objective?

Predict the next token in a sequence.

What is inference?

Running the trained model to generate predictions without performing the normal training weight updates.

What is a base model?

A pretrained language model whose fundamental capability is next-token prediction, before assistant-oriented post-training.

Why isn't a base model automatically ChatGPT?

Because pretraining teaches broad language modeling, while assistant behavior is largely developed through post-training.

28. My Mental Model

A useful personal summary is:

An LLM is a very large neural network that learns statistical patterns in token sequences. During pretraining, it repeatedly tries to predict the next token and adjusts billions of parameters using gradient-based optimization. Once trained, the model can generate text autoregressively by repeatedly predicting the next token. Modern assistant models then undergo additional post-training to make their behavior more useful and instruction-following.
